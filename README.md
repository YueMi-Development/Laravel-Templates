# Laravel Templates

A collection of ready-to-use Laravel starter templates and presets.

## Templates List

| Branch | Category | Description | Stack / Features |
| :--- | :--- | :--- | :--- |
| `main` | Blade | Base template containing baseline architecture, project structure rules, and agent configurations. | Laravel 12.x, PHP 8.3, PSR-12 |
| `vue/brz-roles` | Vue | Laravel Breeze authentication with Vue 3 & Inertia.js, integrated with multi-role access control (Admin, Staff, User), dedicated layouts, and role middleware. | Laravel 12.x, Vue 3, Inertia.js, Tailwind CSS, Role-based Auth |
